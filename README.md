# Job Board Platform UI

## Intern ID

**CITS7582**

## Project Overview

This project is a responsive Job Board Platform UI developed as part of the internship project tasks.

The website provides a modern interface where users can search for job opportunities, filter job listings, sort available jobs, and interact with job application buttons.

## Features

- Responsive job board interface
- Job search functionality
- Location-based search
- Job type filtering
- Salary sorting
- Job listing cards
- Apply Now interaction
- Clear filters functionality
- Responsive mobile navigation
- Modern and clean UI
- Mobile, tablet, and desktop support

## Technologies Used

- HTML5
- CSS3
- JavaScript
